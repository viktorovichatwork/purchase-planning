# Все цифры считает детерминированный Python, LLM только объясняет готовый результат

Количество к заказу, прогноз, плечо, страховой запас, сегменты SKU и сравнение с прошлым запуском считает детерминированный Python: один и тот же вход даёт один и тот же результат, его можно проверить и воспроизвести. LLM получает только готовый выход расчёта (не исходные CSV) и пишет объяснение «почему N», сводку изменений по готовому сравнению, разбор аномалий и черновики писем поставщикам; причины она выбирает из закрытого списка кодов, проставленных расчётом. Каждое число и `sku_id` в тексте LLM автоматически сверяются с выходом расчёта; при несовпадении отчёт публикуется без текста LLM — цифры важнее прозы. LLM никогда не меняет количество, сегмент или решение по наценке.

## Considered Options

- LLM считает или корректирует прогноз — отвергнуто: не воспроизводимо, ошибки в цифрах дорогие (недозаказ в сезон), байер не сможет проверить.
- Без LLM вообще — отвергнуто: объяснения и сводка изменений — то, что делает рекомендацию понятной владельцу и байеру.
