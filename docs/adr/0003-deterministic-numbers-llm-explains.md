# Все цифры считает детерминированный Python, LLM только объясняет готовый результат

Количество к заказу, прогноз, плечо, страховой запас, сегменты SKU и сравнение с прошлым запуском считает детерминированный Python. Один и тот же вход даёт проверяемый и воспроизводимый результат. LLM получает только готовый результат расчёта и использует закрытый список кодов причин для пояснений, сводки изменений, разбора аномалий и черновиков писем поставщикам. LLM никогда не меняет количество, сегмент или решение по наценке.

Каждое число и `sku_id` в пояснении сверяются с результатом расчёта. При несовпадении отбрасывается отдельная фраза, остальные подтверждённые фразы публикуются. При невалидном JSON пропускается весь пакет пояснений.

## Considered Options

- LLM считает или корректирует прогноз — отвергнуто: не воспроизводимо, ошибки в цифрах дорогие (недозаказ в сезон), байер не сможет проверить.
- Без LLM вообще — отвергнуто: объяснения и сводка изменений — то, что делает рекомендацию понятной владельцу и байеру.
