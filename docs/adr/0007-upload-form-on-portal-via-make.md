# Выгрузку загружают через форму на портале, а в репозиторий её кладёт сценарий Make

Уточняет ADR 0004 в части того, как выгрузка попадает в систему. Расчёт в GitHub Actions, публикация на GitHub Pages и история запусков в репозитории остаются как в ADR 0004.

По ADR 0004 выгрузку мог загрузить только участник репозитория с правом записи. Заказчик и проверяющие видели портал, но не могли запустить систему на своих данных. Теперь на портале есть форма: пользователь выбирает шесть CSV и отправляет их. Форма передаёт файлы в webhook сценария Make, а сценарий от имени токена GitHub одним действием кладёт их в `inbox/` ветки `main`, а push запускает workflow «План закупок и Pages». Аккаунт GitHub пользователю не нужен.

Токен — fine-grained, только на этот репозиторий, с правом Contents: write: сценарий только создаёт коммит, а расчёт запускает сам push. Он хранится в ключе Make `github-purchase-planning`, а не в самом сценарии, поэтому сценарий можно менять через API без повторного ввода токена. На публичную страницу токен не попадает. Срок токена — 90 дней; после него загрузка отвечает ошибкой, и в ключ вписывают новый токен.

Форма публичная: загрузить может любой посетитель портала. Для пилота это принято сознательно, на обезличенных данных. Каждая принятая выгрузка сохраняется в истории запусков, поэтому неудачную загрузку откатывают повторной загрузкой эталонной выгрузки. Закрытие доступа — в issue #1.

Пользователь видит статус загрузки на портале: принята и план обновлён, или отклонена с причиной. Отклонённая выгрузка не заменяет опубликованный план.

## Considered Options

- Общая папка Google Диска, которую GitHub Actions проверяет по расписанию, с кнопкой пересчёта через Make. Отвергнута: GitHub читает публичную папку без ключа неофициальным способом, который Google может сломать; проверка по расписанию даёт задержку 15–40 минут; добавляется ещё одна внешняя система.
- Google Apps Script в аккаунте владельца папки. Отвергнут: у владельца нет доступа к Apps Script.
- Пригласить проверяющих в репозиторий с правом записи. Отвергнуто: нужен аккаунт GitHub и ручное приглашение, а право записи открывает и код.
- Пробный расчёт в браузере через Pyodide без публикации. Отложен: не обновляет общий портал и не показывает регулярный запуск, ради которого делается проверка.

## Consequences

- Бесплатный тариф Make: 1000 операций в месяц, 2 активных сценария, до 5 МБ на файл. Одна загрузка — около 13 операций, то есть около 70 загрузок в месяц. Самый большой файл выгрузки сейчас 1,8 МБ.
- Загрузка через веб-интерфейс GitHub в `inbox/` остаётся у владельца репозитория как запасной путь.
