# Уровень сервиса переводится в страховой запас через квантиль ошибки бэктеста

Целевой запас = прогноз на горизонт (плечо поставки + период покрытия) × множитель. Множитель — квантиль отношения «факт / прогноз» из бэктеста на уровне сервиса группы SKU. Страховой запас = целевой запас − прогноз. Учебная формула σ√L не используется: ошибки прогноза большие, а их распределение несимметрично. Квантиль на уровне сервиса — то же, что критическое отношение newsvendor, поэтому экономика потерь (уровень сервиса) и статистика (бэктест) здесь две половины одной формулы.

- Отношение считается по сумме за весь горизонт, а не по месяцам: месячные ошибки частично гасят друг друга, и квантиль по месяцам завысил бы запас.
- Окна бэктеста, в которых есть дефицитные месяцы, исключаются: в них факт занижен.
- Квантили считаются по группе, а не по SKU: у одного SKU слишком мало точек. Группы — регулярный и прерывистый спрос, тип спроса пересчитывается на каждой точке отсчёта, чтобы в оценку не протекало будущее. Сезонные SKU берут свой уровень сервиса.
- Уровни сервиса: регулярный спрос 95%, прерывистый 85%, сезонная категория 75% (остаток после сезона лежит около 10 месяцев). Опоздание поставщика уже входит в плечо и второй раз не закладывается.
- Множитель ограничен ×2 (параметр). Квантиль 95% у регулярного спроса равен 2,55, то есть страховой запас +155% к прогнозу. Это решение владельца, принятое ради оборотного капитала.

Квантили бэктеста на момент решения:

| Группа | p75 | p85 | p95 |
|---|---|---|---|
| Регулярный | 1,31 | 1,62 | 2,55 |
| Прерывистый | 1,30 | 1,80 | 3,63 |
