# Спрос — уровень SKU без дефицитных месяцев × сезонный профиль категории

В выгрузке остатков нет строк с нулём: отсутствие строки за месяц означает нулевой остаток на 1-е число (с 2024-01 так выглядит больше половины SKU-месяцев). Месяцы, начавшиеся с нулевого остатка, — дефицитные: продажи в них не равны спросу, и учить на них прогноз как на «спроса нет» нельзя. Поэтому уровень SKU оценивается только по месяцам с остатком (и только с 2024-01, где остатки известны), а форма сезона берётся из профиля категории по всей истории 2020–2025, а не из истории SKU: у большинства SKU спрос прерывистый, и собственный профиль не оценить. В бэктесте 2024–2026 этот метод дал ошибку WAPE 0,50 без смещения против 0,83 у среднего за 12 месяцев.

## Consequences

- Метрики качества прогноза считаются только по месяцам с остатком — иначе правильный прогноз штрафуется за дефицит.
- «Нет продаж 12 месяцев» не означает «мёртвый»: SKU, у которого всё это время не было остатка, — спящий.
