---
name: plan-purchases
description: Рассчитать план закупок по выгрузке ERP и показать изменения с прошлого запуска.
argument-hint: "[каталог выгрузки]"
disable-model-invocation: true
---

1. Из корня проекта запусти `python -m purchase_planning.runs "<каталог выгрузки>"`. Возьми каталог из `$ARGUMENTS`, по умолчанию используй `.`. Передай путь одним аргументом. Для отдельной истории добавь `--history-dir "<каталог истории>"`. По умолчанию история хранится в `.scratch/purchase-runs`. Используй одну историю для последовательных выгрузок, которые нужно сравнивать.
2. Если команда завершилась с ошибкой, передай причину из вывода. Если отсутствует зависимость, установи пакет командой `python -m pip install -e .` и повтори запуск.
3. При успехе сообщи пути к `index.html` и `report.xlsx` и кратко передай сводку из вывода команды. Для первого запуска сообщи об отсутствии предыдущего результата, для пустого сравнения — «Изменений нет». Если нужны конкретные SKU, возьми числа и коды причин из `diff.json` рядом с отчётом.
